# Book Explorer

A Java-based application for exploring, discovering, and managing books with an intuitive user interface.

## Features

- **Book Discovery**: Browse and search through a vast collection of books
- **Book Details**: View comprehensive information about each book including title, author, description, and ratings
- **Search Functionality**: Quickly find books by title, author, or genre
- **Favorites**: Save your favorite books for easy access
- **User-Friendly Interface**: Clean and intuitive design for seamless navigation

## Installation

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Maven or Gradle (if applicable)

### Steps

1. Clone the repository:
```bash
git clone https://github.com/doniaAdnan-cmd/Book_Explorer.git
cd Book_Explorer
```

2. Compile the project:
```bash
javac -d bin src/**/*.java
```

3. Run the application:
```bash
java -cp bin [MainClassName]
```

## Usage

1. Launch the application
2. Browse available books or use the search feature
3. Click on a book to view detailed information
4. Add books to your favorites collection
5. Manage your book list as needed
